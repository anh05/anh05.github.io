# xAutoML screenshots

Images in this folder (`.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`) appear in the Screenshots gallery on `/projects/xautoml/`, sorted by file name. The caption and alt text come from the file name: `01-dataset-upload.png` becomes "Dataset upload". While the folder has no images, the gallery is not rendered.

Only add screenshots that show nothing private: no user data, credentials or internal URLs.
